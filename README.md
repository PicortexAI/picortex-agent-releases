# PICORTEX Agent

Qui ci sono le versioni di **PICORTEX Agent**, l'applicazione per macOS e Windows con
cui parli con il tuo agente PICORTEX. L'ultima è sempre in
[Releases](https://github.com/PicortexAI/picortex-agent-releases/releases/latest).

Per usarla serve un **codice di abbinamento**, che ti dà chi gestisce il tuo agente.

## Come si installa

**macOS**: scarica il file `.dmg` con **universal** nel nome, che va bene per i Mac
Intel e per quelli Apple Silicon. È firmato e verificato da Apple. Aprilo e trascina
PICORTEX Agent nella cartella Applicazioni; se c'era già una versione, sostituiscila.

**Windows**: scarica il file `.exe` con **Setup** nel nome e aprilo. Si installa per
te, senza chiedere i diritti di amministratore. Il file non è firmato, e Windows può
avvisare che ha protetto il PC: scegli **Ulteriori informazioni** e poi **Esegui
comunque**.

Abbinamenti, argomenti e conversazioni restano dove sono: stanno nella cartella dei
dati, non nell'applicazione, e un aggiornamento non li tocca.

## Gli aggiornamenti

Dalla versione successiva alla 1.6.3, PICORTEX Agent controlla da solo se qui c'è una
versione più nuova della sua e te lo dice con una fascia sopra la conversazione:
**Scarica** apre il browser con il file per il tuo computer, e lo installi sopra
quella di prima, come la prima volta. Non si installa niente da solo.

Ogni versione ha le sue note, e spesso una guida in PDF alla novità principale.
